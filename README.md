# Protein Function Prediction Model

# Dataset Explination

As of now the dataset for this project is the CAFCA 6 Protein Function Kaggle competition Gene Ontology dataset. as said by the Kaggle Competition Dataset description, Gene Ontology or GO is a heirarchy that describes the biological function of genes and gene products at different levels of abstraction. Or as said fron a peer reviewed artice [2] Gene Ontology is an improtant reesource as it descrfibes the functional properties of proteins. This has hads the effect where deep learning, a fast-evolving discipline in data-driven approach, exhibits impressive potential with respect to assigning GO terms to amino acid sequences.
